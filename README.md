# ご当地ガチャ

日本各地の観光スポットをランダムに紹介する、ハッカソン向けのWebアプリです。全国または47都道府県から地域を選び、必要に応じて市区町村まで絞り込んで、Wikipediaの位置情報から次の旅先候補を1件表示します。

## 主な機能

- 「全国」または47都道府県からの抽選
- 都道府県に連動する市区町村の任意絞り込み
- 日本語版Wikipediaの位置付き記事から、観光・文化施設・自然名所を抽出してランダム抽選
- Google マップへの座標リンク
- 読み込み・0件・通信エラー・画像なしの各表示
- 30分間のサーバー内メモリキャッシュ
- キーボード操作と画面幅に配慮したレスポンシブUI

## セットアップ

Node.js 22以降とnpmを使用します。APIキーは不要です。

```bash
npm install
cp .env.example .env.local
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

`WIKIMEDIA_USER_AGENT` はWikimedia APIのアクセス方針に従ってクライアントを識別する値です。公開環境では、`.env.local` の例示URLを運営者へ連絡できるURLまたはメールアドレスへ変更してください。未設定時はアクセス中のアプリURLを使います。

## デモ方法

1. 初期値の「全国からおまかせ」のまま「ガチャを回す」を押します。
2. 特定県の確認には「宮城県」などを選びます。続いて「仙台市青葉区」などの市区町村を任意で選べます。
3. 「市区町村すべて」では県全体、個別の市区町村ではその行政区域に絞ってガチャを回します。
4. 結果の「Google マップで見る」から位置を確認できます。
5. Wikipediaから候補を取得できない場合は、固定データへ切り替えず取得エラーを表示します。

## 構成

- `src/app/`: 画面、スタイル、Route Handler
- `src/components/`: ガチャUIと表示部品
- `src/data/prefecture-search-origins.json`: 都道府県単位のWikipedia位置検索に使う代表座標
- `src/data/municipalities.json`: 市区町村コード・名称・代表座標のローカルスナップショット
- `src/lib/`: 県・市区町村リスト、型、抽選、Wikipedia正規化
- `tests/`: Node.js標準テストランナーによる単体テスト
- `docs/`: 要件定義

## データソースと帰属

観光スポットは[日本語版Wikipedia](https://ja.wikipedia.org/)のGeoSearchで周辺の位置付き記事を検索し、観光・文化施設・自然名所に関係する記事へ絞り込みます。結果には元記事へのリンクを表示します。Wikipediaのコンテンツは各ページに記載されたライセンス条件に従います。画像は作者・個別ライセンスを安全に表示できないため、自動取得しません。

市区町村一覧と自治体代表点には、デジタル庁のアドレス・ベース・レジストリを元にした [Geolonia 住所データ v2](https://github.com/geolonia/japanese-addresses-v2)（CC BY 4.0）を使用しています。アプリには2024年12月25日更新のスナップショットから必要項目だけを収録しています。

## 既知の制約

- 「全国」は最初に47都道府県を等確率で選びます。API失敗や0件では最大4回まで別の県を抽選するため、最終結果の厳密な等確率は保証されません。
- キャッシュはプロセス内メモリのため、再起動やサーバーレス環境のインスタンス切り替えで失われます。
- 写真は通常プレースホルダーを表示します。
- Wikimedia APIの応答速度・稼働状況により、初回取得に時間がかかったり取得エラーになる場合があります。
- 都道府県検索は代表地点から半径10km以内の位置付き記事が対象です。都道府県全域を網羅せず、記事の説明文による絞り込みには掲載漏れや誤分類があり得ます。
- 市区町村検索は自治体代表点から半径10km以内を検索し、記事名または説明に選択地域が含まれる候補だけを採用します。面積の広い自治体では全域を網羅しません。
- 市区町村スナップショット以降に自治体名・区分が変更された場合は、データ更新が必要です。
